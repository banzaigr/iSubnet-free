IPv6 Compression Rules (RFC 5952)

1. Omit Leading Zeros Leading zeros in any 16-bit hexadecimal field (hextet) must be suppressed. For example, 0db8 becomes db8, and a field of 0000 is written as 0.
2. Compress Zero Runs (::) A single contiguous run of all-zero fields can be replaced with a double colon (::). This shorthand can only be used once in an address to prevent ambiguity.
3. RFC 5952 Canonical Rules
• Longest Run: Always compress the longest run of consecutive all-zero fields (e.g. three zero fields rather than two).
• Leftmost First: If zero runs are equal in length, compress the leftmost (first) run.
• No Single Zeros: Never compress a single zero field to :: (e.g. write :0: instead).
• Lowercase: Always write hex characters in lowercase (e.g. db8, not DB8).
Example Compression
Original Address 2001:0db8:0000:0000:0001:0000:0000:0000
1. Omit Leading Zeros 2001:db8:0:0:1:0:0:0
2. RFC 5952 Canonical (Compressed) 2001:db8:0:0:1:: (Compresses the longest run of zero fields at the end)
